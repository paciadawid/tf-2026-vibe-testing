# FD-06 · Checkout — exploration notes

Explored against https://foodora.lovable.app on 2026-09-24, with Playwright MCP from a clean state
(localStorage and sessionStorage cleared).

## Routes

- `/checkout` with items: the checkout form. Page title `Checkout | Foodora`.
- `/checkout` with an empty cart (opened directly): empty state, page title
  `Foodora — Food Delivery from Local Restaurants`.
- Place Order renders the confirmation **in place** — the URL stays `/checkout` (see fd-07.md).

## Elements (role and accessible name as the snapshot shows them)

- `button "Back"`, `heading "Checkout" [level=1]`
- `heading "Delivery Address" [level=3]` and textboxes (labels, placeholders):
  `textbox "Full Name"` (John Doe), `textbox "Street Address"` (123 Main Street),
  `textbox "Apt / Suite"` (Apt 4B), `textbox "City"` (New York), `textbox "Phone Number"`
  (+1 (555) 000-0000), `textbox "Delivery Instructions (optional)"` (Ring doorbell, leave at

  says optional.
- `heading "Payment Method" [level=3]`, `radiogroup` with
  `radio "Credit / Debit Card **** **** **** 4242"` [checked by default],
  `radio "Cash on Delivery Pay when your order arrives"`,
  `radio "Apple Pay Fast & secure checkout"` — use `getByRole('radio', { name: /Apple Pay/ })`.
  Checking works (`aria-checked`).
- `heading "Order Summary" [level=3]`: lines as `1x <dish>` + line price, then `Subtotal`,
  `Delivery Fee`, `Service Fee`, `Total` (same values as the cart), `Estimated delivery: 25-35 min`,
  `button "Place Order"`.
- Empty cart: `heading "Your cart is empty" [level=2]`, *Add some items before checking out.*,
  `button "Browse Restaurants"` → `/`. No form, no Place Order.

## What Place Order did

| Form | Result |
| --- | --- |
| All fields empty | **Order placed** — Order Confirmed!, `FDR-FTPU3T`, Total $15.48 |
| Full Name empty, others filled | **Order placed** — `FDR-E93SON`, Total $45.42 |
| Required filled, Apt / Suite and Instructions blank, Apple Pay | Order placed — `FDR-JZH9K5`, $20.48 |

No validation message appeared in any case. After an order the cart is emptied.

## Where the app already contradicts the spec

- "**Place Order** only places the order when every required field is filled in. Otherwise no
  order is placed, and each missing field shows a message saying what is needed." — an entirely
  empty form places an order; so does a form without Full Name. No field-level message exists.
  (Street Address, City and Phone Number were not tried one at a time; given the empty-form result
  they are expected to fail the same way.)
- The Order Summary shows the same wrong Delivery Fee ($2.99 for every restaurant) and no
  discount line — see fd-05.md.
- `Estimated delivery: 25-35 min` for every restaurant (Sushi Masters advertises 20-30,
  Mediterranean Delight 35-45) — FD-07 territory.
